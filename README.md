# RuLayer

Улучшения поверх русской локализации **Star Citizen**  
(чертежи [BP], майнинг, цвета товаров и др.).

**Не ставит перевод.** Сначала установи русский, затем RuLayer.

## Скачать

Готовая программа: **[Releases](../../releases)** → файл `RuLayer.exe`

## Как пользоваться

1. Установите/обновите перевод (Expanse Union)
2. Скачайте и запустите `RuLayer.exe`
3. Выберите LIVE / PTU / HOTFIX
4. Нажмите **ПРИМЕНИТЬ УЛУЧШЕНИЯ**
5. Запустите игру через RSI Launcher

После патча Star Citizen: снова Expanse Union → снова RuLayer «Применить».
