# RuLayer

Улучшения поверх русской локализации **Star Citizen**  
(чертежи [BP], майнинг, цвета товаров и др.).

**Не ставит перевод.** Сначала установи русский, затем RuLayer.

## Скачать

Готовая программа: **[Releases](../../releases)** → файл `RuLayer.exe`

## Как пользоваться

1. Установите/обновите перевод
2. Скачайте и запустите `RuLayer.exe`
3. Выберите LIVE / PTU / HOTFIX
4. Нажмите **ПРИМЕНИТЬ УЛУЧШЕНИЯ**
5. Запустите игру через RSI Launcher

После патча Star Citizen: обновление русификатора (если доступно) → снова RuLayer «Применить».

## Важно

- Исходный код не публикуется. Распространяется только готовая сборка.
- Разрешено использовать RuLayer.exe для себя.
- Запрещено без согласия автора: выдавать программу за свою, перепродавать, публиковать изменённые версии под другим именем.
- Данные QoL: [StarStrings](https://github.com/MrKraken/StarStrings). Перевод — отдельно.
- Не связано с Cloud Imperium Games / RSI.
