# RuLayer

**Улучшения локализации для Star Citizen (SCMark)**

RuLayer — небольшая программа, которая добавляет в игру удобные подсказки в текстах: метки чертежей **[BP]**, качество майнинга **(RS)**, префиксы оружия и другие QoL-правки.

Работает:
- поверх **русского перевода**, или  
- на **английском** `global.ini`.

Не связан с Cloud Imperium Games / RSI. Community tool.

---

## Возможности

- Установка одной кнопкой с автоматическим бэкапом
- Выбор окружения: **LIVE / PTU / HOTFIX**
- Язык установки: русский или English
- Опции по желанию: чертежи [BP], префиксы оружия, майнинг (RS), грузовые заголовки, репутация, очки сценария
- Обновление таблиц QoL из интернета без переустановки программы
- Откат: «Удалить улучшения» / «Вернуть исходное»
- Интерфейс на русском и английском

## Установка

### Русский язык

1. Сначала установите **любой русский перевод** для Star Citizen.
2. Запустите **RuLayer.exe**.
3. Версию: **LIVE** (или PTU / HOTFIX).
4. **Язык установки** → «Русский / RU».
5. Отметьте нужные опции справа.
6. Нажмите **Установить**.

### English

1. В `user.cfg` игры должна быть строка:  
   `g_language = english`
2. В RuLayer: **Язык установки** → «English / EN».
3. **Установить**.

После установки можно сразу запускать игру. Бэкап сохраняется как `global.ini.rulayer.bak`.

---

## Обновление после патча Star Citizen

1. Обновите русский перевод (если играете на RU).
2. Откройте RuLayer.
3. По желанию нажмите **Обновить data** (скачает свежие таблицы QoL).
4. Снова нажмите **Установить**.

Новый `RuLayer.exe` нужен только если вышла **новая версия программы**.  
Если обновились только таблицы на [RuLayer-Data](https://github.com/shtempels/RuLayer-Data) — достаточно «Обновить data» → «Установить».

Оранжевая надпись «Доступно обновление SCMark» значит: на сервере есть более свежий pack — нажмите **Обновить data**.

---

## Откат

- **Удалить улучшения** / **Вернуть исходное** — восстановление из бэкапа.  
- Либо вручную верните `global.ini` из `global.ini.rulayer.bak`.

---

## Кнопки в программе

| Кнопка | Действие |
|--------|----------|
| **Установить** | Применить QoL к `global.ini` |
| **Обновить data** | Скачать свежие таблицы, не трогая игру |
| **Папка** | Открыть каталог с `global.ini` |
| **RSI Launcher** | Запуск лаунчера RSI |
| **Помощь** | Связь с автором (Discord) |
| **?** | Краткая инструкция |
| **RU / EN** | Язык интерфейса лаунчера |

---

## Важно

- RuLayer **не ставит** русский перевод — только улучшения поверх уже существующего `global.ini`.
- Перед установкой на RU перевод должен быть уже на месте.
- Антивирус иногда ругается на `.exe`, собранные PyInstaller — это обычная ложная сработка. Скачивайте только с этого репозитория (Releases).
